# AI Execution Modes

## Discuss
Explore requirements, identify ambiguity, compare options. No implementation.

## Plan
Produce implementation plan, affected files, risks, dependencies, and acceptance criteria.

## Build
Implement approved work, run validation, and report changes.

## Audit
Review code, architecture, UX, security, compliance, performance, and consistency. No changes unless authorized.

Agents should state their mode before material work.
