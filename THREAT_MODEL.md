# Threat Model

Threats include account takeover, privilege escalation, fraud, payment abuse, data leakage, malicious uploads, injection, SSRF, XSS, API abuse, spam, social engineering, AI prompt injection, tool abuse, insider misuse, supply-chain compromise, and denial of service.

High-risk domains require threat modelling.

AI threats include prompt injection, data exfiltration through tools, unsafe tool chaining, model manipulation, hallucinated authorization, and excessive autonomy.
