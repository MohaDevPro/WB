# Definition of Done

A feature is done only when:
- Requirements are understood.
- Architecture boundaries are respected.
- Code is implemented and reviewed.
- Tests pass.
- Security impact is addressed.
- Accessibility is addressed where applicable.
- Arabic/English localization is complete where applicable.
- Observability exists for critical behaviour.
- Documentation is updated.
- Acceptance criteria are satisfied.
- Deployment and rollback considerations are understood.
