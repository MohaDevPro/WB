# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

أعضاء مجتمع WK، ومديرو المنصة ومديرو المجتمعات والمشرفون، في سياق نقاشات مجتمعية ولقاءات مباشرة عبر Zoom.

## Product Purpose

تثبت V0 دورة استخدام قصيرة: إنشاء حساب، تفعيل البريد، دخول مجتمع، نشر ومناقشة محتوى نصي، ثم التسجيل في حدث مباشر. النجاح هو أن تعمل هذه الدورة بوضوح وأمان مع صلاحيات قابلة للاختبار.

## Positioning

WK يبدأ كمجتمع عام للنقاش والمعرفة مع مجتمعات مغلقة تديرها المنصة مركزيًا، بدل أن يكون مساحة إنشاء ذاتي غير منضبطة.

## Operating Context

يستخدم الأعضاء الويب غالبًا من الهاتف أو سطح المكتب. توجد بيئات local وstaging وproduction. العربية هي اللغة الأساسية للواجهة في V0 مع RTL؛ ويمكن توسعة الإنجليزية لاحقًا.

## Capabilities and Constraints

V0 تشمل Auth بالبريد وكلمة المرور ورقم الجوال كمدخل فقط، تفعيل البريد عبر Resend، Profile بسيط، مجتمعًا عامًا، مجتمعًا مغلقًا بطلب انضمام، مجموعات أساسية، Feed نصيًا، تعليقات، like واحد، إشرافًا بسيطًا، وإحداثًا مباشرًا فرديًا عامًا أو خاصًا عبر Zoom. لا تشمل V0 الملف المهني المتقدم أو Channels أو الدعوات أو النقاط أو السمعة أو Events المتكررة.

## Brand Commitments

الاسم المستخدم في التطبيق هو WK. يجب الحفاظ على الثقة والوضوح وتقليل التعقيد، مع دعم RTL وتباين واضح وحالات loading/error/empty.

## Evidence on Hand

المستودع الأصلي وثائق استراتيجية وهندسية، ولا يحتوي قبل هذه المرحلة على تطبيق قابل للتشغيل. لا توجد صور أو ادعاءات تجارية يجب اختراعها.

## Product Principles

- User value before feature volume.
- Trust before growth.
- Security and privacy by design.
- Arabic-first, accessible UX.
- Modular architecture without premature complexity.

## Accessibility & Inclusion

تستهدف الواجهة WCAG 2.2 AA قدر الإمكان في V0: HTML دلالي، labels واضحة، focus visible، تباين مناسب، دعم لوحة المفاتيح، RTL، واستجابة للهاتف.
