# Technology Stack

Frontend: Next.js, React, TypeScript, Tailwind CSS, shadcn/ui.

Backend: NestJS and TypeScript.

Database: PostgreSQL.

Cache and initial queues: Redis.

Search: PostgreSQL full-text search initially; OpenSearch when semantic or scale requirements justify it.

Storage: S3-compatible object storage.

API: REST/OpenAPI.

Realtime: WebSocket where required.

Containers: Docker.

CI/CD: GitHub Actions.

Observability: OpenTelemetry-compatible telemetry.

Testing: unit, integration, API, E2E, security, accessibility, and performance.

AI: provider-agnostic AI Gateway supporting commercial and open models.

Prefer mature technology for transactional systems. Every major dependency requires security, maintenance, licensing, performance, and operational review.
